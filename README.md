# Flipkart Power BI Dashboard

## Project Overview
This project analyzes Flipkart e-commerce sales data using Microsoft Power BI.

## Features
- Total Revenue
- Total Products Sold
- Total Customers
- Total Orders
- Average Rating
- Revenue by Year
- Revenue by Zone
- Products Sold by Year
- Orders by Year

## Tools Used
- Microsoft Power BI
- DAX
- Power Query
- Excel/CSV
